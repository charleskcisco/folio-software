# Installing Folio

Folio is a writing program. It runs on Mac and Windows. Everything it
needs to turn your writing into a PDF or a Word document is already inside
it — there is nothing else to install.

## Which file do I download?

**Windows:** `Folio_0.1.0_x64-setup.exe`

**Mac:** there are two, and you need the one that matches your machine.
Click the  menu → **About This Mac** and look at the line for **Chip**
or **Processor**:

| It says | Download |
| --- | --- |
| Apple M1, M2, M3, M4… | `Folio_0.1.0_aarch64.dmg` |
| Intel | `Folio_0.1.0_x64.dmg` |

If you download the wrong one it simply will not open. Nothing breaks —
fetch the other one.

## Mac

Open the `.dmg`, drag **Folio** into your Applications folder, and open it
from there. You should not see any warning. If you do, stop and tell me,
because that means something is wrong with the file you downloaded.

## Windows

Run the `.exe`. **Windows will show you a blue box that says "Windows
protected your PC."** This is expected. Click **More info**, then **Run
anyway**.

### Why does that warning appear?

Windows shows it for any program it has not seen many people install
before. Software companies make it go away by buying a *code signing
certificate*, which costs several hundred dollars a year. Folio is free
and made for one classroom, so it does not have one yet.

The warning appears once, when you install. After that Folio opens
normally, like any other program.

### Read this part properly

That warning is not stupid, and it is not there to annoy you. It is
Windows telling you it cannot vouch for this file — and most of the time,
that is a warning you should take seriously and stop.

The reason it is safe to continue *here* is not that warnings don't
matter. It is that you know where this file came from: you got the link
from me, in class, and you downloaded it from that link. That is the only
thing making this different from a file that arrives in an email from
someone you don't know.

So: click through this one, and keep being suspicious of the next one.
If a program you did not go looking for shows you this box, the right
answer is Cancel.
